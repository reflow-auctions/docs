You can customize how auction widgets look and behave directly from the **App embeds** section in the Shopify theme editor. This lets you adjust the storefront experience without editing theme code.

:::info

Widget settings control the appearance and layout of auction elements on your storefront. The exact options available may vary depending on where the widget is shown.

:::

![Shopify theme editor showing App embeds widget customization settings, including collection button, action button layout, theme preset, and custom colors](/img/docs/theme-setup/storefront-customization-1.png)

### Where to customize widgets

All widget display settings are managed inside your Shopify theme editor:

#### 1. Open your Shopify theme editor

In Shopify, go to **Online Store** → **Themes**, then click **Customize** on the theme you want to edit.

#### 2. Open App embeds

In the theme editor sidebar, open **App embeds**.

#### 3. Select the auction embed

Find and expand the auction app embed to view its customization options.

#### 4. Adjust the widget settings

Update the available appearance and behavior settings, then save your changes.

:::tip

Use the live preview in the theme editor while updating settings so you can immediately confirm how the widget will look to customers.

:::

### What you can customize

From the app embed settings, you can control several parts of the widget experience, including:

- **Visibility of extra elements**, such as optional buttons or supporting interface elements
- **Layout behavior**, including how action buttons are arranged in the bidding area
- **Theme presets**, which apply a predefined visual style
- **Custom colors**, so widget colors better match your storefront branding
- **Feature-specific settings**, such as showing a custom button on collection pages

### Key settings explained

#### Enable Custom button in Collections

This setting adds a custom auction-related button to collection pages when supported by the widget configuration. It is useful if you want shoppers to see auction actions before they open an individual product or auction page.

:::note

Turning this on affects how auction actions are presented in collection views. After enabling it, review a collection page in your live preview to make sure the button placement fits your theme layout.

:::

#### Action buttons templates

This controls the layout of the bidding action area. For example, a setting like **Primary Actions First** changes the order or emphasis of buttons without changing the underlying auction logic.

Use this option when you want to improve clarity for buyers or match the interaction style of your storefront.

#### Theme Preset

Theme presets apply a ready-made visual style to the widget. This is the fastest way to update the widget appearance if you do not want to configure each color manually.

#### Custom colors

If you need more control, you can define your own widget colors. Common color fields may include:

- **Primary color** for main buttons and key highlights
- **Secondary color** for supporting elements
- **Active color** for selected or emphasized states
- **Light color** for light backgrounds or contrast areas
- **Dark color** for text, dark backgrounds, or stronger contrast

### Best practices for styling widgets

- Choose colors that match your storefront branding while keeping text and buttons easy to read.
- Preview collection and product pages after making changes so you can confirm the widget looks consistent across placements.
- Use presets first if you want a quick setup, then fine-tune individual colors only if needed.
- When enabling extra buttons or layout changes, check spacing and alignment on both desktop and mobile views.

:::warning

Some styling choices that look good in the editor may reduce readability on your live storefront if contrast is too low. Always review buttons, labels, and interactive elements before publishing changes.

:::

### When to use these settings

Use widget customization settings when you want to:

- Match the widget design to your store theme
- Highlight important auction actions more clearly
- Show auction actions in collection pages
- Create a more polished buying and bidding experience without editing theme code

These settings make it easier to tailor the auction experience to your storefront design while keeping setup manageable from the Shopify theme editor.
