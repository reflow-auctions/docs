## What theme blocks do in Reflow Auctions

Reflow Auctions uses Shopify theme blocks to display auction content on your storefront. After you install the app, you can open **Shopify Admin** and place Reflow Auctions blocks inside your theme so shoppers can see auction details, interact with listings, and browse your auction pages.

You will usually work in two places:

- **Apps > Reflow Auctions** to create and manage your **Events** and **Auctions**
- **Online Store > Themes > Customize** to control where auction content appears in your storefront

:::info

Before adding theme blocks, make sure you already created at least one auction in **Apps > Reflow Auctions**. Theme blocks control storefront placement, but your auction content is managed inside the app.

:::

## Open the Shopify Theme Editor

1. **Go to your theme settings**

   In Shopify Admin, open **Online Store**, then **Themes**.

2. **Open your current theme**

   In the **Current theme** section, click **Customize**.

3. **Find Reflow Auctions**

   Inside the Theme Editor, use the left sidebar to work with **App embeds** and app blocks from **Reflow Auctions**.

## Enable the Reflow Auctions app embed

Before your blocks can work correctly on the storefront, enable the app embed for Reflow Auctions.

1. **Open App embeds**

   In the Theme Editor, open **App embeds**.

2. **Turn on Reflow Auctions**

   Find **Reflow Auctions** in the list and enable it.

3. **Save the change**

   Click **Save** in the top-right corner.

:::warning

If the Reflow Auctions embed is turned off, auction widgets may not appear correctly even if you already added blocks to the page layout.

:::

## Add Reflow Auctions blocks to a page

Once the app embed is enabled, you can place Reflow Auctions blocks on the storefront pages where customers should see auction content.

1. **Choose the page template**

   In **Online Store > Themes > Customize**, switch to the page or template where you want auction content to appear.

2. **Add an app block**

   In the left sidebar, add a block and select a block from **Reflow Auctions**.

3. **Move the block into position**Drag and drop the block to the section where it should appear. You can reorder blocks at any time.
4. **Preview the layout**Use the Theme Editor preview to confirm the block appears in the right place and fits the rest of the page.
5. **Publish your changes**

   Click **Save** after you finish arranging the layout.

## Where to place theme blocks

### Auctions list page

If you want customers to browse multiple auction items in one place, add Reflow Auctions blocks to your **Auctions list** page. This is the best option when you want a dedicated storefront page for current listings.

### Product page templates

If an auction is tied to a Shopify product, place Reflow Auctions blocks on the relevant product template so shoppers can view auction information directly on the product page.

### Event-based storefront experiences

If you organize auctions inside **Events** in the app, use the Theme Editor to present those auctions in a way that matches the event experience you want customers to see on the storefront.

:::tip

After you create or update auctions in **Apps > Reflow Auctions**, return to the storefront preview to confirm your theme layout still highlights the right auction content.

:::

## How theme blocks fit into the Reflow Auctions workflow

1. Create your auction structure in **Apps > Reflow Auctions**.
2. Organize listings with **Events** if needed.
3. Configure the auction in **Auctions**.
4. Open **Online Store > Themes > Customize**.
5. Enable **App embeds** for **Reflow Auctions**.
6. Add and arrange Reflow Auctions blocks on the correct storefront page.
7. Click **Save** to publish the layout.

## Tips for a cleaner storefront setup

- Keep auction blocks close to the main product or listing content so customers do not miss them.
- Preview your layout after every major change to make sure the page still reads clearly on the storefront.
- If you use multiple templates, verify that you added Reflow Auctions blocks to the correct one before saving.

:::note

Existing Reflow Auctions documentation notes that some features and block behavior can vary by Shopify theme. Dawn and Empire are recommended themes.

:::

## Troubleshooting

### I added a block but nothing shows on the storefront

Check **App embeds** first and confirm **Reflow Auctions** is enabled. Then verify you clicked **Save** in the Theme Editor.

### My auction content is on the wrong page

Return to **Online Store > Themes > Customize** and confirm you are editing the correct page or template, such as the **Auctions list** page or the correct product template.

### I created auctions in the app, but customers still cannot see them

Make sure the auctions were created in **Apps > Reflow Auctions**, then confirm the storefront layout includes Reflow Auctions blocks and that the app embed is turned on.

### The layout does not look right in my theme

Reorder the blocks in the left sidebar and preview the page again. Theme support can vary, so the exact placement options may differ depending on your Shopify theme.
