## Invoice expiration time

Use **Invoice expiration time** to control how long customers have to pay an invoice before it expires.

![Checkout settings showing the Invoice expiration time field with a number input and a Days or Hours selector](/img/docs/settings/checkout-settings-1.png)

### How it works

This setting has two parts:

- **Number field** — enter how long the invoice should stay open.
- **Time unit selector** — choose whether that number is in **Days** or **Hours**.

For example:

- `30 + Days` keeps the invoice open for 30 days.
- `12 + Hours` keeps the invoice open for 12 hours.

### When to use each option

- **Days** — best when customers usually need more time to complete payment.
- **Hours** — best for time-sensitive invoices that should expire sooner.

:::note

Changes to this setting also apply to invoices that are already open.

:::

### Set the invoice expiration time

1. **Enter a value**Type the amount of time into the input field.

#### 2. Choose the time unit

Select **Days** or **Hours** from the dropdown.

3. **Save your changes**Save the setting so the new expiration time is used for invoices.

:::tip

Use **Hours** if you want faster payment turnaround, and use **Days** if customers may need longer to review or complete payment.

:::
