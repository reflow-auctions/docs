---
title: "Notification Center"
description: "Review important Reflow Auctions app updates in one place with the Notification Center, without leaving the Admin app."
---

The **Notification Center** brings important app updates into one place so admins can quickly review what needs attention without leaving the Admin App.

:::info

The Notification Center is available from the bell icon in the Admin App header on every Admin App page, including **Settings**.

:::

### Open the Notification Center

#### 1. Find the bell icon

Look for the bell icon in the top header of the Admin App.

#### 2. Check for new activity

If a new notification is waiting, a visual indicator appears on the bell icon.

#### 3. Review your notifications

Select the bell icon to open the Notification Center and read the latest updates.

:::note

The new notification indicator is tracked separately for each user in the store. It clears after that user opens the new notification.

:::

### What each notification includes

Each notification gives you the information you need to understand what happened and where to take action.

- **Title** that summarizes the update
- **Short message** explaining what happened
- **Source area**, such as Subscription, Buyers Fee, Events, Auctions, Orders, Products, Storefront, Integrations, or System
- **Date and time** shown in your local time zone
- **New notification indicator** for newly received items

### How notifications are organized

- Notifications are sorted from **newest to oldest**.
- If you have many notifications, the list can be **scrolled inside the Notification Center**.
- Some notifications disappear automatically after the related issue is resolved.

### Supported notifications

### Release updates

You can receive app release update notifications directly in the Admin App. These updates help you stay aware of new features, improvements, and important changes.

### Subscription limit warnings

Subscription-related warnings appear in the Notification Center when your store is approaching or has exceeded its configured usage limit.

Examples include:

- **Usage limit is running low** — increase your Subscription Limit before reaching the threshold
- **Subscription Limit has been exceeded**

:::tip

If you receive a usage warning, open **Settings** and increase your subscription limit as soon as possible to avoid interruption.

:::

After you successfully increase the subscription limit in **Settings**, subscription-related notifications are removed automatically.

### Buyers Fee functionality paused

If the Buyers Fee product is changed or removed in a way the app does not support, the Notification Center shows a message explaining that Buyers Fee functionality is paused.

The notification also tells you what to do next, including enabling **Product creation** if needed so functionality can resume.

:::warning

If Buyers Fee functionality is paused, review the notification promptly. Leaving the issue unresolved may prevent Buyers Fee from working as expected.

:::

### Important alerts that still appear outside the Notification Center

Some critical warnings remain visible elsewhere in the Admin App instead of appearing only in the Notification Center.

- **App embed is disabled**
- **Usage limit warning at 100%** on the related page

:::note

These alerts stay outside the Notification Center because they require immediate attention in the area where the issue occurs.

:::

### Best practices

- Check the bell icon regularly, especially after making changes in **Settings**.
- Review new notifications as soon as they appear so you can resolve issues before they affect store operations.
- Use the source area shown in the notification to quickly identify where to go next.
