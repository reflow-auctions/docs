---

Use the **Auctions** list to review all auctions in one place, check their progress, and quickly narrow the list to the items you need. You can also monitor auction status and results from the related **Event** view.

:::info

You can manage auctions from both the **Auctions list** page and the **Event details** page, depending on whether you want a full cross-event view or details for a single event.

:::

### Where to view auctions

- **Auctions list page:** Best for reviewing auctions across multiple events, filtering by status, and sorting the table to find specific records quickly.
- **Event details page:** Best for viewing auctions in the context of a single event and checking related event information at the same time.

![image](/img/docs/managing-auctions/auction-list-filters-1.png)

### Filter the auction list

The auction table includes filters that help you locate auctions based on their current state or associated event.

![image](/img/docs/managing-auctions/auction-list-filters-2.png)

#### 1. Open the Auctions list

Go to the **Auctions** page to view all available auctions in a table.

#### 2. Filter by status

Use the **Status** filter to show only auctions in a specific state, such as active, completed, or another available status in your workspace.

#### 3. Filter by event

Use the **Event** filter to limit the list to auctions connected to one event.

#### 4. Review the filtered results

The table updates so you can focus only on the auctions that match your selected filters.

:::tip

Combine **Status** and **Event** filters when you need to find a smaller set of auctions quickly, such as completed auctions from a specific event.

:::

### All available filters

Besides **Status** and **Event**, you can filter the auction list by sales results and bidding values.

![Auctions list with the Number of bids filter open, showing From and To fields, next to the Status, Event, Features, Sale type, Payment status, Bid increment, Starting bid and Current bid filters](/img/docs/managing-auctions/auction-list-filters-5.png)

| Filter | What it finds |
|---|---|
| **Status** | Auctions in a specific state, such as scheduled, running or completed. |
| **Event** | Auctions that belong to one event. |
| **Features** | Auctions with **Buy It Now** or **Make Offer** turned on. |
| **Sale type** | How the auction ended: **Auction**, **Buy It Now** or **No sale**. |
| **Payment status** | The payment state of the auction's invoice, for example **Invoice open**, **Paid** or **Payment expired**. |
| **Number of bids** | Auctions with a number of bids in a range. |
| **Bid increment** | Auctions with a bid increment in a range. |
| **Starting bid** | Auctions with a starting bid in a range. |
| **Current bid** | Auctions with a current bid in a range. |

:::note

**Sale type** and **Payment status** appear only when [Auction Cart & Checkout](/bidding-purchasing/auction-cart-checkout) is enabled. **Features** appears only when Buy It Now or Make Offer is enabled for your store.

:::

### Filter by a range

**Number of bids**, **Bid increment**, **Starting bid** and **Current bid** filter by a range of values.

#### 1. Open the filter

Click the filter you want to use, for example **Number of bids**.

#### 2. Enter the range

Enter a value in **From**, **To**, or both. Fill in only **From** to find values from that number up, or only **To** to find values up to that number. Number of bids takes whole numbers; the money filters accept decimals.

#### 3. Review the results

The table updates to show only the auctions in that range. Click **Clear** in the filter to remove it.

:::tip

Use **Number of bids** with **From** and **To** set to `0` to find auctions that didn't get any bids, for example to [relist them](/managing-auctions/relisting-auctions).

:::

### Sort the list to prioritize your work

Sorting helps you organize auctions by the information that matters most for your task. This makes it easier to review time-sensitive auctions, compare values, or find the next item that needs attention.

![image](/img/docs/managing-auctions/auction-list-filters-3.png)

- Sort by timing-related columns to bring upcoming or recent auctions into view first.
- Sort by value-related columns to identify higher- or lower-value auctions faster.
- Re-sort the table as needed when switching from monitoring activity to reviewing results.

:::note

Available sort options depend on the columns shown in your auction table.

:::

### Monitor auction status and results

As auctions progress, you can use the list view to keep track of their current status and review outcomes once they are complete. This helps administrators monitor activity without opening each auction individually.

- Check the table for the latest auction status.
- Use filters to isolate only the auctions you want to review.
- Open the related event when you need more event-specific context.

### View auctions from an event

If you are already working inside an event, you can review its auctions directly from the **Event details** page. This is useful when you want to stay focused on one event and its related auction activity.

![image](/img/docs/managing-auctions/auction-list-filters-4.png)

### Best practices

- Use the **Auctions list** page when you need a broad view across events.
- Use the **Event details** page when you are focused on one event only.
- Apply filters before reviewing results to reduce noise in the table.
- Sort the list based on urgency, timing, or value depending on the task you are completing.
