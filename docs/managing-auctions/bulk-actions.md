Bulk editing lets you update multiple auctions at the same time from the **Auctions** list. You can use it from the main Auctions page or from an individual event’s auction list to make the same change across many items at once.

:::info

Bulk actions help you save time when you need to update auction settings across several listings instead of editing each auction one by one.

:::

![Bulk action controls in the Auctions list showing selected auctions and available actions such as setting active status, canceling, editing starting bid, bid increment, and start or end dates](/img/docs/managing-auctions/bulk-actions-1.png)

### What you can update in bulk

After selecting multiple auctions, you can apply actions such as:

- Set auctions as **Active**
- Set auctions as **Canceled**
- Edit the **starting bid**
- Edit the **bid increment**
- Edit the **start date** or **end date**
- **Enable** or **disable Buy It Now**
- **Hide** or **Show Widget**
- **Relist Auction**
- **Delete** auctions

### Bulk edit auctions

#### 1. Open the Auctions list

Go to the **Auctions** list from the Auctions page or from the event where the auctions are located.

#### 2. Select the auctions you want to update

Use the checkboxes next to each auction. After you select one or more auctions, the bulk action toolbar appears above the list.

#### 3. Choose a bulk action

Select the action you want to apply, such as changing the auction status, updating prices, adjusting dates, or managing **Buy It Now**.

#### 4. Review the results

If all selected auctions meet the requirements for that change, the update is applied to the valid auctions.

:::tip

If you want to update nearly every auction in the list, select a few auctions first and then use **Select all items** when it appears.

:::

### How validation works

All normal auction rules still apply during bulk edits. The system checks each selected auction before applying the change.

- If an auction passes validation, it can be updated.
- If an auction does not pass validation, it is highlighted so you can identify it quickly.
- You can remove invalid auctions from the selection and continue with the rest, or fix the issue and try again.

:::warning

Bulk changes are not always available for every selected auction. For example, some date changes may be blocked if bidding activity has already started on an auction.

:::

![Auctions list showing validation errors during a bulk update, with affected auctions marked and a message explaining that some selected auctions could not be modified](/img/docs/managing-auctions/bulk-actions-2.png)

### If some auctions cannot be updated

When one or more selected auctions cannot be changed, the page shows which rows have an issue. This lets you decide how to proceed without losing the rest of your work.

- **Uncheck the highlighted auctions** to continue updating only the valid ones.
- **Fix the problem** on the affected auctions, then run the bulk action again.

:::note

This behavior helps you make changes efficiently while still protecting auction data from invalid updates.

:::

### Deleting auctions in bulk

You can also remove multiple auctions at once using the bulk actions menu.

:::danger

Deleting auctions is a destructive action. Make sure you review your selection carefully before continuing.

:::
