The **Event details** page includes **Event Analytics**, which gives you a complete view of how a single Event is performing. It brings together headline metrics, revenue insights, auction status breakdowns, and bidder engagement in one place so you can evaluate performance without opening each auction individually.

:::info

All analytics on this page are calculated only for the Event you are currently viewing.

:::

## What you can do on this page

- Review key Event performance metrics
- Monitor auction progress and status distribution
- Track bidding activity and Buy It Now performance
- Analyze revenue and payment collection
- Measure bidder engagement and conversion
- Compare metrics across different time periods
- Refresh analytics to retrieve the latest available data

## Event Analytics overview

The dashboard is organized into several sections so you can review performance from different angles.

### At the top of the page

- **Date range selectors** let you compare the current Event period with another time period.
- **Last time refreshed** shows when the analytics were most recently updated.
- **Refresh** reloads the latest available analytics for the Event.

:::tip

Use comparison date ranges to quickly spot changes in bidding activity, revenue, or auction completion between similar Events.

:::

## Summary metrics

The summary cards provide a quick snapshot of the most important Event statistics.

### Total draft orders created

Displays the total number of draft orders created from auctions in this Event.

### Formula

**Total draft orders created = All draft orders created from auction wins + Buy It Now purchases**

### Total auctions

Displays the total number of auctions included in this Event.

### Formula

**Total auctions = Scheduled + Running + Finished + Canceled + Draft auctions**

### Total bids

Displays the total number of bids placed across all auctions in this Event. Buy It Now purchases are not included.

### Formula

**Total bids = All regular bids + Proxy bids placed in this Event across Active Auctions**

### Buy It Now sales count

Displays the number of successful Buy It Now purchases made in this Event.

### Formula

**Buy It Now sales count = Number of completed Buy It Now purchases**

### Scheduled auctions

Displays the number of auctions that have not started yet.

### Formula

**Scheduled auctions = Count of auctions with Scheduled status**

### Running auctions

Displays the number of auctions that are currently active.

This card helps you understand how many auctions are live right now within the Event.

### Finished auctions

Displays the number of auctions that have ended.

Use this metric to measure how much of the Event has already been completed.

### Canceled auctions

Displays the number of auctions that were canceled before completion.

This helps you separate incomplete auctions from successfully completed ones when reviewing Event performance.

### Draft auctions

Displays the number of auctions still saved as drafts and not yet published.

Use this card to confirm whether all intended auctions were launched as part of the Event.

## Revenue metrics

The revenue section shows the financial performance of the Event and how it changes over time.

### Total event price

Shows the total revenue generated by the Event across completed auction outcomes.

> Formula: Total event price = Current winning prices for Running auctions + Winning prices for Finished auctions + Buy It Now purchases

### Average price per auctions

Shows the average revenue generated per auction in the Event.

> Formula: Average price per auction = Total event price / Number of Scheduled + Running + Finished auctions + Buy It Now Purchases

### Total auctions revenue

This chart breaks down Event revenue by outcome type, helping you understand how much revenue came from finished auctions compared with sold or Buy It Now outcomes.

> Formula: Total auctions revenue = Finished auction revenue + Buy It Now revenue

:::note

If a comparison period is selected, percentage changes shown on revenue cards are calculated against that comparison period.

:::

## Collection metrics

These charts help you understand how much revenue has been collected and how much is still outstanding.

### Buy It Now collected vs not collected orders

Shows the split between collected and uncollected Buy It Now order value for the Event.

### Collected vs not collected draft orders

Shows the split between collected and uncollected draft orders created from Event results.

:::warning

Collection metrics reflect order payment status. If orders are still awaiting payment, the uncollected portion may remain high even when auction activity is strong.

:::

## Bidder engagement metrics

The bidder section helps you measure participation and conversion within the Event.

### Bidder win rate

Shows how effectively active bidders are converting participation into wins.

- **Bidders**: Total number of bidders associated with the Event
- **Active**: Bidders who placed bids during the Event
- **Winning**: Bidders who won at least one auction
- **Win rate**: The share of participating bidders who became winning bidders

Use this section to understand whether an Event is attracting enough competition and converting bidder interest into completed outcomes.

## How to review Event performance

#### 1. Open the Event

Go to the **Events** section and select the Event you want to review.

#### 2. Review the headline metrics

Start with the summary cards to understand total auction volume, bid activity, draft orders created, and Buy It Now sales.

#### 3. Check auction status distribution

Look at scheduled, running, finished, canceled, and draft auctions to see how far the Event has progressed.

#### 4. Evaluate revenue and collection

Review total revenue, average auction value, and collected versus uncollected amounts to understand financial performance.

#### 5. Measure bidder engagement

Use bidder win rate and bidder counts to assess participation and conversion.

#### 6. Refresh if needed

Click **Refresh** to retrieve the latest available analytics before sharing or acting on the data.

## When analytics may appear limited

If an Event has few or no auctions yet, some analytics cards may show little data or zero values. This is expected when:

- The Event has not started
- No auctions have been added yet
- Auctions are still in draft or scheduled status
- No bids or Buy It Now purchases have occurred yet
- The Event ended before Event Analytics became available (July 8, 2026)

:::note

Draft orders are typically created after auction outcomes are processed, so this metric may remain at zero until the Event has ended and auction results have been finalized.

:::

## Best practices

- Review analytics after major Event milestones, such as launch, midpoint, and close.
- Compare against a previous period to identify performance trends more clearly.
- Check both revenue and collection metrics before using Event totals in reporting.
- Use bidder win rate together with total bids to understand both interest and conversion.
