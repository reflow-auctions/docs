The **Dashboard** gives Admins a real-time summary of auction performance across all events. Use it to track revenue, bidder activity, sales volume, and event or auction status from one place. The date filter and comparison tools make it easy to review performance for a single day or a custom date range, then measure results against a previous period.

:::info

The Dashboard shows high-level results across your events and auctions. For item-by-item or event-specific analysis, use the Event Details page.

:::

![Dashboard showing revenue cards, bidder metrics, event totals, and auction status summaries](/img/docs/analytics-reporting/dashboard-1.png)

## Use the Dashboard

#### 1. Choose a timeframe

Use the date picker at the top of the Dashboard to view results for **today** or for a custom date range.

#### 2. Compare performance

Turn on the comparison option to compare the selected timeframe with a previous period, such as the previous day, week, month, or year.

#### 3. Review top metrics

Start with the summary cards to quickly understand revenue, average auction value, bidding activity, and buyer engagement.

#### 4. Check event and auction status

Scroll down to see how many events are active or finished, and how many auctions are active, scheduled, running, finished, canceled, or still in draft.

## Customize the Dashboard

Click **Customize dashboard** to rearrange Dashboard cards and adjust their width on desktop.

![image](/img/docs/analytics-reporting/dashboard-2.png)

Drag cards to reorder them within their current sections: **Main overview**, **Events**, or **Auctions**. Cards cannot be moved between sections. On mobile, cards use the full screen width and can only be reordered.

![image](/img/docs/analytics-reporting/dashboard-3.png)

Use **Undo** and **Redo** to review your changes. Click **Save** to apply them or **Discard** to return to the last saved layout.

Click **Reset to default**, then **Save**, to restore the original Dashboard layout.

## Key metrics on the Dashboard

### Revenue metrics

- **Total events revenue**: The total revenue generated across the selected timeframe.
- **Average price per auction**: The average sale amount per auction.
- **Total Buy It Now revenue**: Revenue generated from Buy It Now purchases.

### Activity metrics

- **Total events**: The number of events included in the selected timeframe.
- **Total auctions**: The total number of auctions across those events.
- **Total bids**: The total number of bids placed.
- **Buy It Now sales count**: The number of purchases completed through Buy It Now.

### Bidder metrics

- **New bidders**: Bidders participating for the first time during the selected period.
- **Active bidders**: Bidders who placed bids during the selected period.
- **Winning bidders**: Bidders who won one or more auctions.

## Event status summary

The Dashboard groups events by status so you can quickly understand how much of your activity is currently live versus completed.

- **Active**: Events that are currently running or available to participants.
- **Finished**: Events that have ended.

## Auction status summary

The auction status section helps you monitor where inventory sits in the auction lifecycle.

- **Active**: Auctions currently available in an active event.
- **Scheduled**: Auctions prepared to go live later.
- **Running**: Auctions actively accepting bids.
- **Finished**: Auctions that have ended.
- **Canceled**: Auctions that were stopped before completion.
- **Draft**: Auctions that have been created but are not yet published.

:::tip

Use comparisons to spot trends, not just totals. A revenue total may look strong on its own, but comparing it to the previous period helps you see whether performance is improving, holding steady, or declining.

:::

## How to read comparisons

When comparison is enabled, each summary card can show the change from the previous period. This helps you quickly identify shifts in performance across revenue, bidder participation, and sales activity.

- A higher value than the previous period can indicate stronger engagement or sales.
- A lower value can highlight areas that may need follow-up, such as fewer bids or reduced Buy It Now activity.
- Use the current value together with the comparison value to understand both scale and trend.

:::note

Metrics on the Dashboard are based on the date range you select. If totals look different from another report, first confirm that both views are using the same timeframe.

:::

## What the Dashboard helps you answer

- How much revenue did our events generate during a specific period?
- Are bidder participation and winning activity increasing or decreasing?
- How many auctions are currently live, finished, or still in draft?
- How much revenue is coming from bidding versus Buy It Now sales?
- How many events are active right now compared with completed events?
