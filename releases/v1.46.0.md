## Features

- Introduced a global Popcorn Bidding setting to enable or disable the feature across the store.

## Fixes

- Added a Features and Number of Bids Filters to the Auctions table.
- Included a Number of Bids column in the Auctions table.
- Restored the ability to enable or disable Buy It Now before Auction Start for scheduled auctions.
- Implemented separate validation messages for invalid products and Draft products when creating auctions.
- Updated all Admin App date and time displays to use the merchant's Store Time Zone.
- Improved handling of canceled auction notifications when large numbers of auctions are canceled simultaneously.
- Enhanced the Automation section with an updated Workflows block.
- Optimized cart validation performance for high-volume storefront carts.
- Clarified the distinction between Direct Bids and Proxy Bids in Winning Bid notifications.
- Refactored primary action buttons across Bid, Customer, and Buy It Now modals for better consistency.
- Applied default multi-level sorting to the Auctions list (All tab).
- Reorganized widget visibility settings into dedicated Mobile, Desktop, and Both sections.
- Resolved product variant metafield update failures for Draft auctions.
- Streamlined internal token management and supporting infrastructure.
- Fixed various minor bugs, UI inconsistencies, and performance issues across Admin App and Storefront components.
