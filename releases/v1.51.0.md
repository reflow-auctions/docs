## Features

- Launched user notifications in the Storefront Notification Center. – [Learn more](/storefront-features/storefront-notifications-for-bidders) 
- Implemented Dashboard customization, including layout adjustments and widget management. – [Learn more](/analytics-reporting/dashboard#customize-the-dashboard)
- Introduced an Invoice expiration time setting for unpaid invoices. – [Learn more](/settings/checkout-settings)

## Fixes

- Restricted Event archiving until the estimated end time has passed.
- Prevented auction creation and relisting when an item’s available inventory is reserved in an Open invoice.
- Preserved payment availability for existing invoices when their items are used in new or relisted auctions.
- Added Notification Center alerts for automatically canceled auctions.
- Isolated Storefront Auctions Widget styles to prevent them from overriding Shopify theme styles.
- Corrected the status displayed while orders are being generated from bids.
- Replaced default-domain links in Auction Invoice emails with links using the store’s custom domain.
- Updated the app configuration with the required Shopify Events settings.
- Modernized the application by upgrading React Router dependencies and improving route compatibility.
- Fixed various minor bugs, UI inconsistencies, and performance issues across the Admin app and Storefront components.
