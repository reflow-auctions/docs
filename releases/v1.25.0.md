## Features

- Introduced enhanced bid flow supporting two Bid Types (available under the \[Straight bid\] feature flag; disabled by default)

## Fixes

- Implemented custom date picker for bulk editing auction start/end dates
- Streamlined event statuses to only "Active" and "Finished"
- Enabled previous/next navigation buttons for Auction details page
- Resolved issue where auction cancellations weren’t logged in Activity
- Updated and refactored Cancel, Keep Auction, and Close buttons
- Reinstated display logic for bids within canceled auctions
- Polished minor bugs and UI inconsistencies
