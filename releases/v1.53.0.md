## Fixes

- Introduced a **Payment status** filter and **No sale** sale type in the Auctions table.
- Expanded Invoices with an **Expired** tab and **Resend invoice** action.
- Enabled hiding and unhiding cards in Dashboard and Analytics customization.
- Implemented **Mark all as read** in the Notification Center.
- Linked invoice products and customers to Shopify and refreshed **Last updated** after invoice changes.
- Strengthened bulk editing and relisting when individual batches fail.
- Applied compact formatting to large storefront amounts.
- Enhanced navigation in the enlarged gallery view and bidder updates for parallel auctions.
- Continued the Admin App migration to Polaris Web Components.
- Resolved various minor bugs and UI inconsistencies.
