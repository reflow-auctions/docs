## Features

- Introduced the **Order Complete** functionality, including handling of taxes and shipping costs, the **Order Cost Estimator** page, and the ability for users to select a delivery method and address _(available via DB enablement, disabled by default)_.
- Implemented **Auction Widget layout templates**, available from the **App Embed page**.
- Enabled downloading of **usage charges by month** from the App Settings page.
- Launched the **My Auctions proxy page** _(no changes for existing merchants using the User’s Auctions Widget)_.
- Added customizable **color settings for app widgets** _(available from the App Embed page)_.
- Provided storefront **translation support** _(Spanish and Arabic)_.

## Improvements

- Optimized the performance of the **Dashboard** and **Events** pages.
- Added support for the **Horizon theme**.
- Automated the installation of the **Auctions Widget**.
- Relocated the **Auction Image Gallery** under the **Auction Widget settings**.
- Developed the **Edit Column** functionality for Auctions Table.
- Enhanced the **Onboarding guide**.
- Integrated the Watchers counter with the Auction Image Gallery functionality.

## Fixes

- Resolved minor bugs and UI inconsistencies.
