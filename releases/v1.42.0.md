## Features

- Introduced simplified Onboarding guide for Merchants
- Enabled automatic injection of the Auction Widget to simplify storefront setup for merchants new to Shopify
- Presented Items Summary Page for the Storefront – [Learn more](https://docs.reflowauctions.com/bidding-purchasing/draft-orders#items-summary-page)
- Delivered Bidder Profile UI extension on Customers page – [Learn more](https://docs.reflowauctions.com/bidders/bidder-profile)
- Added Hide/Show Auction Widget functionality (Single & Bulk)

## Improvements

- Improved Auction lifecycle handling (auto-cancel when product is deleted)
- Updated Date picker UI in Relist & Edit modals
- Strengthened UI extension on Products
- Activated usage charges monitoring on billing cycle reset
- Added translation preview script with version history support
- Included Taxes information in Bid / Custom / Buy it now modals
- Enhanced Admin App with Presenters for Auctions and Events Pages
- Refined Collections behavior when filters are applied
- Optimized slug loading during scrolling
- Resolved minor bugs and UI inconsistencies.
