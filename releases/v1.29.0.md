## Features

- Introduced Auto-send Invoice for Draft Orders
- Delivered Live Notifications for the Admin App
- Refactored Draft Order/Order creation to use SQS, preventing Lambda timeout issues

## Fixes (User side)

- Added Buy It Now button to Blocks and the My Auctions page
- Unified layout by placing Bid and Custom buttons in one line
- Adjusted Buy It Now Modal to prevent truncation of value titles
- Redesigned Bids history Modal for both mobile and desktop
- Checked and refined styles for new bidding modals
- Centralized styles and constants
- Polished minor bugs and UI inconsistencies

## Fixes (Admin app)

- Provided Bulk Action option to Disable Buy It Now
- Enabled automatic marking of Draft and Canceled Auctions as Sold/Buy It Now when items are purchased before the auction start
- Removed Reserve Price feature code
- Centralized styles and constants
- Addressed various minor bugs and UI inconsistencies
