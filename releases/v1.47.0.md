## Features

- Introduced a redesigned Event details analytics page with an improved layout and expanded metric tooltips that now include calculation formulas – [Learn more](/analytics-reporting/event-metrics)

## Fixes

- Added Starting Bid, Current Bid, and Bid Increment filters to the Auctions table in Admin App.
- Sorted products by creation date, newest first, in the Add Auctions tab.
- Corrected the Previous and Next auction navigation order on the Auction Details page.
- Expanded Activity management on the Event Details page.
- Added missing validation for auction defaults, properties, date fields, and numeric filter inputs.
- Improved Bulk Edit start and end date defaults and restored missing currency symbols in bid increment fields.
- Added keyboard shortcuts for faster navigation in the Admin App.
- Improved Watchlist navigation to related products on the Storefront.
- Resolved onboarding issues after subscription, My Auctions navigation inconsistencies, tooltip positioning, bid confirmation button styling, and multiple UI inconsistencies across the Admin App and Storefront.
- Refined internal routing validation, infrastructure components, and overall performance.
