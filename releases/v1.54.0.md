## Features

- Introduced the storefront Auction Notifications page, configurable in **Settings → Pages**. – [Learn more](/storefront-features/storefront-notifications-for-bidders#auction-notifications-page)
- Enabled creating auctions directly from the Shopify product page. – [Learn more](/products/product-auction-history#create-an-auction-from-the-product-page)
- Added "Last chance to pay" invoice reminders. – [Learn more](/settings/last-chance-reminders)
- Added a step-by-step setup guide to the Dashboard. – [Learn more](/quick-start/installation#complete-the-quick-setup-guide)
- Implemented automatic management of an Auctions collection in Shopify, with configurable collection types in Automation settings. – [Learn more](/automation/auction-collections)

## Fixes

- Expanded Invoices with Status, Subtotal and Date filters, column customization, a bulk **Resend invoices** action, and resending invoices through Shopify Flow.
- Upgraded auction relisting and queued relisting and auction creation from Shopify Flow.
- Allowed editing Buy It Now for running auctions and adding Draft products to events.
- Added inventory visibility and filtering to product selection, plus a bulk **Remove** action for products with errors.
- Updated the Bid History display, error states and Documentation links across the Admin App.
- Moved **Save as draft** and **Publish** to the page header and removed redundant Save buttons.
- Improved accuracy of bid alerts and invoice notifications in My Auctions, the Auction Cart and the Notification Center.
- Strengthened billing reliability for usage records and buyer's fees.
- Resolved various minor bugs and UI inconsistencies.
