## Features

1. Introduced the **Make Offer** functionality for users, which included:

- Integrated the _Make Offer_ option on the **Auction Details** page
- Implemented a new **My Offers** tab within the **My Auctions** page
- Enabled **messaging** between users and admins within the offer flow
- Supported **real-time updates** for offer status and communication
- Launched **Make Offer Discounts** for items purchased through the offer flow

1. Delivered full Make Offer support in the Admin app, including:

- Developed a dedicated **Offers Page**
- Created an **Auction Offers** page for managing user offers
- Added **Offer History** tracking for each offer session
- Enhanced the **Auction Details** page to support Make Offer interactions
- Enabled core feature settings on the **Settings Page**

1. Implemented **real-time notifications** for users related to the Make Offer activity

## Improvements

- Added the **price display** to the **\[Buy It Now\]** button on the user side
- Improved **image resolution rendering performance** in the **Auctions Table** of the Admin App

**Note:**

All functionalities related to the **Make Offer** feature were placed behind a Make offer **Feature Flag**.

To enable and use the feature:

- Switch on the makeOffer Feature Flag in the **database (features Table)**
- Once activated, the feature becomes fully available to both users and admins
