## Features

- Redesigned Admin Settings page to comply with Shopify guidelines for the "Built for Shopify" badge.
- Changed the workflow for order creation to streamline the process (order -> instead of draft order).
- Updated Featured Products display by consolidating multiple blocks into a single app block.

## Fixes

- Increased components in My Auctions to match the new design.
- Enhanced the components on the Auction Page to match the new design guidelines.
- Improved page navigation flow for Admin App, making sure the current page opens before the new one.
- Refactored components on My Auctions and Auction Pages for improved performance.
- Fixed breadcrumb navigation issue in Admin App where the wrong page was highlighted when accessing the Dashboard.
