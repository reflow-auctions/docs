## Improvements

- Added real-time updates for the Event Page
- Changed the \[Status\] dropdown to two separate buttons: \[Save as Draft\] and \[Publish\] for the \[Add Auctions\] flow
- Implemented new indexes to improve query performance and overall speed of the production database
- Enabled display of auctions and collection blocks for users who are not signed in
- Provided the ability to delete products directly from the generated products pop-up
- Introduced currency exchange functionality for billing, allowing dynamic exchange rate application

## Fixes

- The loading time of the Event Details Page has been reduced by three times as a result of SQL rewriting and removal of duplicate queries
- Added a comma as a thousands separator for numerical values on the Dashboard
- Disabled the Start/End Date fields after the first bid is placed
- Implemented hover tooltips to provide additional context for table columns
- Resolved the issue where invalid starting/ending dates were displayed incorrectly on mobile devices (iOS) in the Auctions Table
- Fixed the issue where the next opened tab on the Event Page inherited auctions from the previously opened tab
- Added functionality to display the current page number across all pages for the Tables in the App
- Resolved issues with date picker validation
- Fixed issue where a product or collection reappeared in a pop-up after performing a search
- Investigated and fixed the issue with broken task-running within the code pipelines
- Addressed other minor bugs
