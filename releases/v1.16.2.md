## Improvements

- Upgraded filters section on the \[Active\] and \[Ended\] Tabs.
- Updated the toast message shown for slow internet connections with clearer wording.
- Removed the increment/decrement buttons for bid amounts from the \[Bid\] modal.
- Changed the notification message when a bid becomes invalid.
- Swapped the wording for hiding and watching in the popover menu.
- Added a new design state to the Admin Panel pages to clearly indicate when billing plan limits are exceeded.
- Created design for the "Feature Products" section.
- Developed documentation for Billing System Feature.

## Fixes

- Fixed an issue that affected the sorting functionality for bids when sorted by lowest/highest bid.
- Implemented additional validation to verify that auction statuses on the "My Auctions" page are correctly displayed and functional.
- Optimized the performance of the "My Auctions" page.
- Replaced "Default" sorting option by "Time: ending soonest" (for \[Active\] Tab) and "Most Active" (for \[Ended\] Tab) sorting options for a more relevant user experience.
- Resolved an issue with identical bid amounts.
- Improved the design of custom alerts for better visibility.
