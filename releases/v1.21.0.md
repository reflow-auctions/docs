## Features

- Developed Critical Notifications feature
- Activated Price Override capability for line items in Draft Orders and Orders
- Implemented comparison data functionality for the Dashboard Info Cards
- Introduced global \[Tags\] fields for Draft Orders, Orders, and Products, generated via the Generate Products functionality

## Fixes

- Introduced \[Custom\] button to the Collection Block
- Improved auction display by including the \[Canceled Auction\] state
- Resolved pagination issue on the Generated Products page
- Revised shop/redact logic for Critical Notifications email list
- Lifted backend limits for Bid Increment Value in the Admin App
- Enabled email dispatch to recipients listed under \[Critical Notifications\]
- Enforced validation for the total auction count based on starting bids in the Billing System
- Retained pagination and filter states when navigating back to the Event Details page
- Corrected sidebar menu behavior when usage limits are exceeded during the billing cycle
- Applied new state logic to the Bidders Table post-auction cancellation
- Resolved issue with missing images for auctions added as separate products
- Addressed various minor bugs and UI inconsistencies
