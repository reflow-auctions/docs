## Features

- Introduced Event Archiving functionality, allowing merchants to archive Events. automatically make Auctions read-only and manage Event archiving through Shopify Flow.

## Fixes

- Improved the Storefront by adding validation for bid confirmation modals, preventing background scrolling while viewing the Auction Gallery, standardizing notification card layout.
- Added a tooltip to the Auction Widget displaying the Auction End Date.
- Enhanced Event Analytics with loading states for KPI cards and charts.
- Added Amount and Date/Time filters to the Bids page in Admin App.
- Improved the Event Details page by adding Event description support, redesigning the Analytics button and enhancing tooltips.
- Updated the Notification Center by changing the unread indicator to red.
- Completed the latest Shopify Package Upgrade, including API Version and Extensions migration, Webhooks improvements and Authentication Hardening.
- Improved overall stability by fixing onboarding after subscription, preserving scroll position in Logs, preventing Draft Order creation for banned bidders.
- Fixed various minor bugs, UI inconsistencies, and performance issues across Admin App and Storefront components.
