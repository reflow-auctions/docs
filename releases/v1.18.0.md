## Features

- Revamped the Dashboard Page

- Re-designed Create Auction and Auction Details Pages for better user experience

- Enabled automatic order creation post-auction conclusion
- Established a billing plan for the app

- Implemented error handling for smoother order generation

- Optimized data retrieval to prevent redundant requests on the Dashboard Page
- Boosted the loading speed of the Dashboard for improved performance
- Created a timeline feature for the Event Page to visualize event flow
- Reorganized sidebar page sequence for intuitive navigation
- Removed the “Create New” button from the Auctions Page
- Hardcoded a 10% buyer's fee in accordance with new Shopify\`s requirements
- Adapted the Auctions List table for responsive mobile viewing
- Removed the hardcoded dollar sign ($) across the system for localization flexibility
- Embedded header within an iframe for better Admin App management
- Smoothed out the Max Bid Value display for better aesthetics
- Introduced an “Unsaved Changes” state in the Admin Panel for better clarity
- Added a dropdown with Draft and Active Statuses options for generated products
- Corrected the dashboard statistics when applying a data range filter
- Improved the deployment process to allow seamless updates without downtime
- Fixed the issue of parallel product generation handling
- Enhanced search and filtering capabilities on the Auctions List Page
