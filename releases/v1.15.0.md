## Features

- Improved the workflow for deleting taxes from orders.
- Updated auction photos when the associated product photo changed.
- Redesigned the Admin Bids page to align with Shopify’s "Built for Shopify" guidelines.
- Added Dev Features flags functionality.

## Fixes

- Improved security for the app.
- Implemented signature verification mechanism for enhanced security.
- Added shop/update webhook to handle shop domain updates.
- Implemented uninstall webhook to handle app uninstallation.
- Added compliance webhook (customers/data\_request; customers/redact; shop/redact) in the Partner Dashboard for handling GDPR-related requests.
- Improved Socket broadcast handling to ensure messages are scoped correctly to auctions and bids across stores.
- Updated auction lookup logic to validate user permissions by store.
- Hidden the Original amount remains in unauthorized requests.
- Logged correct entries for the store during product generation.
- Enhanced admin-side functionality to handle store\_id more effectively.
- Investigated and prepared for wrapping the app block functionality to apply for collection.
- Resolved issue where the login form was not shown for unauthenticated users on the product page.
- Fixed the re-fetch flow during auctions for the mobile version of the app.
- Optimized My Auction filter to cancel previous pending requests when a new filter is applied.
