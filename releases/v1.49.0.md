## Features

- Introduced the Relist Auctions that are not collected Shopify Flow action.

## Fixes

- Updated the new Auction Status model.
- Split the Active Auctions tab into Scheduled and Running tabs.
- Expanded Shopify Flow by adding Event ID to the Event ends trigger and combining Ban bidder and Unban bidder into a single action.
- Enhanced Event Analytics with improved chart interaction, responsive layouts and data formatting.
- Added Cancellation Reason selection to the Auction Cancellation confirmation modal.
- Updated the Event details page with redesigned Analytics button and improved tooltips.
- Refined the Storefront with real-time Watch count updates, improved Auction Gallery behavior, and updated widget tooltips.
- Completed additional Shopify platform upgrades, including webhook reliability improvements and framework updates.
- Resolved issues with archived Event behavior, Logs pagination, and various UI and performance improvements across the Admin App and Storefront.
