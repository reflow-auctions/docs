# Mantle → Docusaurus Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the HeyMantle-hosted help center (reflow.mantledocs.com) with a Docusaurus site in `reflow-auctions/docs`, deployed to GitHub Pages at `https://docs.reflowauctions.com` and editable through Pages CMS.

**Architecture:** A static Docusaurus 3 site (docs served at `/`, release notes as a blog at `/releases`). A throwaway Node migration script scrapes Mantle once, converts its HTML (including Mantle's custom `<m-*>` components) to plain Markdown, downloads every image, and splits the release-notes page into one post per version. GitHub Actions builds every push/PR and deploys `main` to Pages; Pages CMS commits edits to `main`.

**Tech Stack:** Node 22, Docusaurus 3.10.2 (classic preset), `@docusaurus/plugin-client-redirects` 3.10.2, `@easyops-cn/docusaurus-search-local` 0.55.3, cheerio 1.2.0 + turndown 7.2.4 (migration only), `node:test`, GitHub Actions, Pages CMS.

**Spec:** `.design/2026-10-14-mantle-to-docusaurus-design.md`

## Global Constraints

- Site URL `https://docs.reflowauctions.com`, `baseUrl: '/'`, `trailingSlash: false`. Never `/docs/` in URLs.
- Doc URL paths identical to Mantle: `/<section>/<page>`.
- Releases: file `releases/v<x.y.z>.md`, URL `/releases/v<x.y.z>`, front matter `title: "v<x.y.z>"` and `date: YYYY-MM-DD`. No date in file names or URLs.
- Release dates copied exactly from Mantle (v1.15.0 and v1.16.0 stay 2024).
- Release section headings only from the spec mapping: `## Features`, `## Improvements`, `## Improvements (Admin app)`, `## Fixes`, `## Fixes (User side)`, `## Fixes (Admin app)`. Unknown labels must fail the migration.
- Content files are `.md` (CommonMark via `markdown.format: 'detect'`), never `.mdx`.
- Mantle components convert to plain Markdown ("simple" mode): admonitions, ordered lists, `###` headings, bullet lists. No custom React components.
- Zero `heymantle.com` / `mantledocs.com` references in `docs/`, `releases/`, `src/`, `static/`, or root config files.
- Images live in `static/img/docs/<section>/<page>-<n>.<ext>` and are referenced as `/img/docs/...`.
- Build must `throw` on broken links, anchors, Markdown links, and Markdown images.
- Edits go straight to `main`. No Mantle chat widget. No Algolia.
- Never print or commit secrets. Pushes use `$GITHUB_TOKEN` from the environment.

## Prerequisites (owner)

- `GITHUB_TOKEN` env var with `contents: write` + `pull_requests: write` on `reflow-auctions/docs` (fine-grained PAT). Needed from Task 1 Step 9 onward. Without it, the owner pushes the `migration` branch instead.

## Branching

All work happens on branch `migration` in `/var/minis/workspace/docs` (already cloned, empty). Task 1 opens a PR to `main`; CI builds every push. Task 8 merges it, which triggers the first deploy.

**Local builds:** verified working in iSH (about 8–12 minutes per `npm run build`). If a build ever gets killed (OOM/SIGKILL), use the PR's CI `build` job as the build check for that step and say so in the task report.

**Environment notes for executors (iSH on iOS):**
- `file_write` into brand-new directories can create entries the shell can't `stat` (seen with `src/css`, `.github`). Create directories with `mkdir -p` **in the shell first**, then write files, and confirm with `ls -la` before building. If a dot-directory gets stuck ("File exists" but `ls` can't see it), build the tree in a fresh clone directory.
- Heredocs containing `(` inside quoted JSON can trip BusyBox `sh` parsing. Write files with `file_write`, not heredocs.
- Mantle returns **403 to Python's default User-Agent**; Node `fetch` with the UA in `run.mjs` works.
- `npm install` takes about 5 minutes and `npm run build` about 8–12 minutes here. Use `timeout: 1800` on those calls.

`scripts/check-content.mjs`:
```js
// CI guard for content rules the Docusaurus build can't enforce.
// Usage: node scripts/check-content.mjs   (exits 1 on any problem)
import fs from 'node:fs';
import path from 'node:path';

const ROOT = process.cwd();
const MANTLE = /heymantle\.com|mantledocs\.com/i;
const TEXT_EXT = /\.(md|mdx|js|mjs|cjs|json|ya?ml|css|html|txt|xml|svg)$/i;
const SCAN = ['docs', 'releases', 'src', 'static', 'docusaurus.config.js', 'sidebars.js', '.pages.yml'];

function walk(p) {
  if (!fs.existsSync(p)) return [];
  if (fs.statSync(p).isFile()) return [p];
  return fs.readdirSync(p).flatMap((n) => walk(path.join(p, n)));
}

/** Pure check over [{file, content}]; returns a list of problem strings. */
export function findProblems(files) {
  const problems = [];
  for (const { file, content } of files) {
    if (TEXT_EXT.test(file) && MANTLE.test(content)) problems.push(`${file}: references Mantle`);
    if (/^releases\/[^/]+\.md$/.test(file)) {
      const fm = /^---\n([\s\S]*?)\n---/.exec(content)?.[1] ?? '';
      const title = /^title:\s*"?([^"\n]+)"?\s*$/m.exec(fm)?.[1];
      const date = /^date:\s*"?([^"\n]+)"?\s*$/m.exec(fm)?.[1];
      const name = path.basename(file, '.md');
      if (!/^v\d+\.\d+\.\d+$/.test(title ?? '')) problems.push(`${file}: title must look like v1.2.3 (got ${title})`);
      else if (name !== title) problems.push(`${file}: file name must be ${title}.md`);
      if (!/^\d{4}-\d{2}-\d{2}$/.test(date ?? '')) problems.push(`${file}: date must be YYYY-MM-DD (got ${date})`);
    }
  }
  return problems;
}

if (import.meta.url === `file://${process.argv[1]}`) {
  const files = SCAN.flatMap((p) => walk(path.join(ROOT, p))).map((abs) => ({
    file: path.relative(ROOT, abs).split(path.sep).join('/'),
    content: TEXT_EXT.test(abs) ? fs.readFileSync(abs, 'utf8') : '',
  }));
  const problems = findProblems(files);
  for (const p of problems) console.error(`✗ ${p}`);
  console.log(problems.length ? `${problems.length} problem(s)` : `✓ ${files.length} files OK`);
  process.exit(problems.length ? 1 : 0);
}
```

### Task 3: HTML → Markdown converter

**Files:**
- Create: `scripts/migrate/convert.mjs`
- Test: `scripts/migrate/convert.test.mjs`

**Interfaces:**
- Produces: `rewriteHref(href: string, slugToPath: Record<string,string>): string`. It maps Mantle URLs to site-relative paths, maps `/resources/release-notes` → `/releases`, resolves bare slugs (`/dashboard` → `/analytics-reporting/dashboard`), and leaves external links unchanged.
- Produces: `convertHtml(html: string, opts): string` (Markdown ending in `\n`). `opts`:
  - `resolveImage(src: string, alt: string): string` (required): the returned value becomes the image `src`.
  - `slugToPath?: Record<string,string>`
  - `knownPaths?: Set<string>`: internal links whose path (minus `#hash`) isn't in the set are unlinked (text kept) and reported via `onDeadLink?(rawHref)`.
  - `resolveAsset?(href): string | null`: called for `cdn.heymantle.com` **links** (videos). A string relinks; `null`/missing unlinks.
- Throws `Unknown Mantle component <m-x>` for any `<m-*>` tag outside the known set.

**Real-site facts the tests encode** (from surveying all 34 pages on 2026-10-14): components are `m-tip/note/info/warning/danger`, `m-steps>m-step[title]`, `m-accordiongroup>m-accordion[title]`, `m-cardgroup>m-card[title,href?]`, and `m-frame`. Admonitions and images nest inside steps and accordions. Card bodies are sometimes bare text with no `<p>`. Four card/inline links point to pages that 404 on Mantle (`/make-offer`, `/checkout-rules`, `/quick-start/creating-auctions`, `/configuration/settings`). Three walkthrough videos are linked from the Mantle CDN.

import * as cheerio from 'cheerio';
import TurndownService from 'turndown';

const ADMONITIONS = {
  'm-tip': 'tip',
  'm-note': 'note',
  'm-info': 'info',
  'm-warning': 'warning',
  'm-danger': 'danger',
};
const KNOWN_M_TAGS = new Set([
  ...Object.keys(ADMONITIONS),
  'm-steps', 'm-step', 'm-accordiongroup', 'm-accordion',
  'm-cardgroup', 'm-card', 'm-frame',
]);
const OLD_HOSTS = /^https?:\/\/reflow\.mantledocs\.com/;

/**
 * Rewrite a Mantle link to a site-relative path.
 * slugToPath maps a bare page slug ("checkout-settings") to its full path
 * ("/settings/checkout-settings"); Mantle accepts both forms.
 */
export function rewriteHref(href, slugToPath) {
  if (!href) return href;
  let h = href;
  if (OLD_HOSTS.test(h)) h = h.replace(OLD_HOSTS, '') || '/';
  if (!h.startsWith('/')) return href; // external (notion.so, shopify, mailto…)
  const [pathPart, hash] = h.split('#');
  let path = pathPart.replace(/\/$/, '') || '/';
  if (path === '/resources/release-notes') path = '/releases';
  else if (/^\/[a-z0-9-]+$/.test(path) && slugToPath[path.slice(1)]) {
    path = slugToPath[path.slice(1)];
  }
  return hash ? `${path}#${hash}` : path;
}

function makeTurndown() {
  const td = new TurndownService({
    headingStyle: 'atx',
    bulletListMarker: '-',
    codeBlockStyle: 'fenced',
    emDelimiter: '_',
  });
  td.keep(['kbd']);
  // "- item" / "1. item" with continuation lines indented to the marker width.
  td.addRule('listItem', {
    filter: 'li',
    replacement: (content, node) => {
      const parent = node.parentNode;
      let marker = '- ';
      if (parent.nodeName === 'OL') {
        const start = Number(parent.getAttribute('start') || 1);
        marker = `${start + Array.prototype.indexOf.call(parent.children, node)}. `;
      }
      const body = content.replace(/^\n+/, '').replace(/\n+$/, '')
        .replace(/\n/g, `\n${' '.repeat(marker.length)}`);
      return marker + body + (node.nextSibling ? (/\n\s*\n/.test(content.trim()) ? '\n\n' : '\n') : '');
    },
  });
  return td;
}

/**
 * Convert one Mantle #page-content inner HTML string to Markdown.
 * opts.resolveImage(src, alt) -> new src string (required)
 * opts.slugToPath -> {slug: '/section/slug'}
 * opts.resolveAsset(href) -> replacement URL, or null to unlink; called for
 *   links to Mantle-hosted files (cdn.heymantle.com), e.g. videos
 * opts.knownPaths -> Set of valid site paths; internal links to anything else
 *   are unlinked (text kept) and reported via opts.onDeadLink(href).
 */
export function convertHtml(html, opts) {
  const $ = cheerio.load(`<div id="root">${html}</div>`, null, false);
  const root = $('#root');

  // Fail loudly on any Mantle component we don't know how to convert.
  root.find('*').each((_, el) => {
    if (el.tagName.startsWith('m-') && !KNOWN_M_TAGS.has(el.tagName)) {
      throw new Error(`Unknown Mantle component <${el.tagName}>`);
    }
  });

  // Strip inline styles and Mantle classes; drop empty paragraphs.
  root.find('[style]').removeAttr('style');
  root.find('[class]').removeAttr('class');
  root.find('p').each((_, el) => {
    const p = $(el);
    if (!p.text().trim() && p.find('img').length === 0) p.remove();
  });

  // Images: rewrite src (downloads happen in resolveImage).
  root.find('img').each((_, el) => {
    const img = $(el);
    const alt = (img.attr('alt') || '').trim();
    img.attr('src', opts.resolveImage(img.attr('src'), alt));
    img.attr('alt', alt);
  });

  // Links.
  const linkOrUnlink = (a, rawHref) => {
    if (/^https?:\/\/cdn\.heymantle\.com\//.test(rawHref || '')) {
      const to = opts.resolveAsset ? opts.resolveAsset(rawHref) : null;
      if (to) a.attr('href', to).removeAttr('target').removeAttr('rel');
      else a.replaceWith(a.contents());
      return;
    }
    const href = rewriteHref(rawHref, opts.slugToPath || {});
    if (opts.knownPaths && href.startsWith('/') && !opts.knownPaths.has(href.split('#')[0])) {
      opts.onDeadLink?.(rawHref);
      a.replaceWith(a.contents());
      return;
    }
    a.attr('href', href).removeAttr('target').removeAttr('rel');
  };
  root.find('a[href]').each((_, el) => linkOrUnlink($(el), $(el).attr('href')));

  // m-frame: unwrap.
  root.find('m-frame').each((_, el) => { $(el).replaceWith($(el).contents()); });

  // Innermost-first so nested components convert correctly.
  const reversed = (sel) => root.find(sel).toArray().reverse();

  // m-steps -> <ol>, each step -> <li><p><strong>title</strong></p>…</li>
  for (const el of reversed('m-steps')) {
    const ol = $('<ol></ol>');
    $(el).children('m-step').each((_, step) => {
      const title = $(step).attr('title') || '';
      const li = $('<li></li>');
      if (title) li.append($('<p></p>').append($('<strong></strong>').text(title)));
      li.append($(step).contents());
      ol.append(li);
    });
    $(el).replaceWith(ol);
  }

  // m-accordion -> <h3>title</h3> + content
  for (const el of reversed('m-accordiongroup')) {
    const parts = [];
    $(el).children('m-accordion').each((_, acc) => {
      parts.push($('<h3></h3>').text($(acc).attr('title') || ''));
      parts.push(...$(acc).contents().toArray());
    });
    $(el).replaceWith(parts);
  }

  // m-card -> <li><strong>[title](href)</strong> — text</li>
  for (const el of reversed('m-cardgroup')) {
    const ul = $('<ul></ul>');
    $(el).children('m-card').each((_, card) => {
      const title = $(card).attr('title') || '';
      const href = $(card).attr('href');
      const strong = $('<strong></strong>');
      if (href) {
        const a = $('<a></a>').text(title);
        strong.append(a);
        linkOrUnlink(a, href);
      } else strong.text(title);
      const li = $('<li></li>').append($('<p></p>').append(strong));
      // Card text is sometimes bare (no <p>); wrap it so it isn't glued to the title.
      const body = $(card).contents();
      li.append(body.filter((_, n) => n.type === 'tag' && /^(p|ul|ol|div)$/.test(n.tagName)).length ? body : $('<p></p>').append(body));
      ul.append(li);
    });
    $(el).replaceWith(ul);
  }

  // Admonitions: placeholder elements turndown renders as ::: blocks.
  for (const el of reversed(Object.keys(ADMONITIONS).join(','))) {
    const div = $('<div></div>').attr('data-admonition', ADMONITIONS[el.tagName]);
    div.append($(el).contents());
    $(el).replaceWith(div);
  }

  // <li><p>text</p></li> -> <li>text</li> so simple lists stay tight.
  root.find('li').each((_, el) => {
    const kids = $(el).children();
    if (kids.length === 1 && kids[0].tagName === 'p') $(kids[0]).replaceWith($(kids[0]).contents());
  });

  const td = makeTurndown();
  td.addRule('admonition', {
    filter: (node) => node.nodeName === 'DIV' && node.getAttribute('data-admonition'),
    replacement: (content, node) =>
      `\n\n:::${node.getAttribute('data-admonition')}\n\n${content.trim()}\n\n:::\n\n`,
  });

  let md = td.turndown(root.html());
  md = md.replace(/[ \t]+$/gm, '').replace(/\n{3,}/g, '\n\n').trim() + '\n';
  return md;
}

import * as cheerio from 'cheerio';

const VERSION_RE = /^v(\d+\.\d+\.\d+)\s+(\d{2})\/(\d{2})\/(\d{4})$/;

// Spec: "Release section label mapping". Keys are normalized (lowercase,
// trailing colon stripped, dashes unified to "-").
export const LABEL_MAP = {
  'features': 'Features',
  'main improvements': 'Improvements',
  'improvements': 'Improvements',
  'main improvements - admin app': 'Improvements (Admin app)',
  'other fixes/improvements': 'Fixes',
  'fixes/improvements': 'Fixes',
  'main fixes and improvements': 'Fixes',
  'other fixes': 'Fixes',
  'user side - main fixes/improvements': 'Fixes (User side)',
  'admin app - main fixes/improvements': 'Fixes (Admin app)',
};

function norm(text) {
  return text.replace(/\s+/g, ' ').trim();
}

export function normalizeLabel(text) {
  return norm(text).replace(/:$/, '').replace(/[–—]/g, '-').toLowerCase();
}

// Bold-only paragraphs that are content, not section labels. Kept as-is and
// listed in the migration report for a human to tidy.
export const NOT_LABELS = new Set(['note', 'resolved']);

/**
 * Is this top-level element a section label? Any short <h3>/<div>/<p> whose
 * text is a known label maps to its heading. NOT_LABELS stay paragraphs.
 * An unknown short <h3>, <div>, or bold-only <p> throws.
 */
export function labelFor($, el) {
  const text = norm($(el).text());
  if (!text || text.length > 60) return null;
  const tag = el.tagName;
  const boldOnly =
    tag === 'p' && $(el).children().length === 1 &&
    $(el).children('strong').length === 1 && norm($(el).children('strong').text()) === text;
  const key = normalizeLabel(text);
  if (NOT_LABELS.has(key)) return null;
  // Known labels are recognized in any wrapper (some were pasted as plain text).
  if (['h3', 'div', 'p'].includes(tag) && LABEL_MAP[key]) return LABEL_MAP[key];
  const isLabelShape = tag === 'h3' || tag === 'div' || boldOnly;
  if (!isLabelShape) return null;
  throw new Error(`Unknown release section label: "${text}"`);
}

/**
 * Split the release-notes #page-content HTML into releases.
 * Returns [{version: 'v1.53.0', date: '2026-09-24', html: '<…>'}], newest first,
 * with section labels replaced by <h2> headings and <hr> separators removed.
 */
export function splitReleases(contentHtml) {
  const $ = cheerio.load(`<div id="root">${contentHtml}</div>`, null, false);
  const releases = [];
  let current = null;
  for (const el of $('#root').children().toArray()) {
    const text = norm($(el).text());
    const m = /^h[1-4]$/.test(el.tagName) ? VERSION_RE.exec(text) : null;
    if (m) {
      current = { version: `v${m[1]}`, date: `${m[4]}-${m[2]}-${m[3]}`, parts: [] };
      releases.push(current);
      continue;
    }
    if (!current) continue; // page intro (title, blurb, m-note) is dropped
    if (el.tagName === 'hr') continue;
    const heading = labelFor($, el);
    current.parts.push(heading ? `<h2>${heading}</h2>` : $.html(el));
  }
  return releases.map(({ version, date, parts }) => ({ version, date, html: parts.join('') }));
}

import * as cheerio from 'cheerio';

/** Parse Mantle's sidebar into [{label, section, pages:[{path, slug, label}]}]. */
export function parseNav(html) {
  const $ = cheerio.load(html);
  return $('#docs-sidebar .Navigation-Group').toArray().map((g) => {
    const pages = $(g).find('a.Navigation-Page-Link').toArray().map((a) => {
      const path = $(a).attr('href');
      const [, section, slug] = path.split('/');
      return { path, section, slug, label: $(a).text().trim() };
    });
    return {
      label: $(g).find('.Navigation-Group-Label').first().text().trim(),
      section: pages[0]?.path.split('/')[1],
      pages,
    };
  });
}

/** Title, description and inner content HTML of one Mantle page. */
export function parsePage(html) {
  const $ = cheerio.load(html);
  const content = $('#page-content');
  if (content.length !== 1) throw new Error('No #page-content on page');
  return {
    title: $('h1.Page-Title').first().text().trim(),
    description: ($('meta[name="description"]').attr('content') || '').trim(),
    contentHtml: content.html(),
  };
}

/** Front matter block. JSON strings are valid YAML double-quoted scalars. */
export function frontMatter(fields) {
  const lines = Object.entries(fields)
    .filter(([, v]) => v !== undefined && v !== '')
    .map(([k, v]) => `${k}: ${typeof v === 'number' ? v : JSON.stringify(v)}`);
  return `---\n${lines.join('\n')}\n---\n\n`;
}

/** "<slug>-<n>.<ext>" for the n-th image (1-based) on a page. */
export function imageFileName(slug, n, src) {
  const ext = (new URL(src).pathname.match(/\.(png|jpe?g|gif|webp|svg)$/i)?.[1] || 'png').toLowerCase();
  return `${slug}-${n}.${ext}`;
}

    resolveImage: (src) => {
      const name = imageFileName(slug, queue.length + 1, src);
      queue.push({ src, rel: `static/img/docs/${section}/${name}` });
      return `/img/docs/${section}/${name}`;
    },
  });
  for (const { src, rel } of queue) {
    await write(rel, Buffer.from(await (await get(src)).arrayBuffer()));
    report.images++;
  }
  for (const { href, name } of assets) {
    const file = path.join(ASSET_ARCHIVE, name);
    const have = await fs.stat(file).then(() => true, () => false);
    if (!have) {
      await fs.mkdir(ASSET_ARCHIVE, { recursive: true });
      await fs.writeFile(file, Buffer.from(await (await get(href)).arrayBuffer()));
    }
    report.videos.push(`${mdFile}: ${name} → ${videoMap[name] || 'UNLINKED (add to scripts/migrate/video-links.json)'}`);
  }
  for (const m of md.matchAll(/\((https:\/\/www\.notion\.so\/[^)\s]+)\)/g)) report.notion.push(`${mdFile}: ${m[1]}`);
  if (mdFile.startsWith('releases/')) {
    for (const m of md.matchAll(/^\*\*[^*\n]+\*\*$/gm)) report.boldOnly.push(`${mdFile}: ${m[0]}`);
  }
  return md;
}

async function main() {
  const nav = parseNav(await text(`${BASE}/quick-start/welcome`));
  const navPaths = nav.flatMap((g) => g.pages.map((p) => p.path)).sort();
  const sitemap = [...(await text(`${BASE}/sitemap.xml`)).matchAll(/<loc>([^<]+)<\/loc>/g)]
    .map((m) => new URL(m[1]).pathname).sort();
  if (JSON.stringify(navPaths) !== JSON.stringify(sitemap)) {
    throw new Error(`Nav and sitemap differ:\nnav=${navPaths}\nsitemap=${sitemap}`);
  }
  const slugToPath = Object.fromEntries(nav.flatMap((g) => g.pages.map((p) => [p.slug, p.path])));
  knownPaths = new Set([...navPaths.filter((p) => p !== RELEASES_PATH), '/releases']);

  for (const [gi, group] of nav.entries()) {
    await write(`docs/${group.section}/_category_.json`,
      JSON.stringify({ label: group.label, position: gi + 1 }, null, 2) + '\n');

    for (const [pi, page] of group.pages.entries()) {
      const html = await text(BASE + page.path);
      const { title, description, contentHtml } = parsePage(html);

      if (page.path === RELEASES_PATH) {
        for (const r of splitReleases(contentHtml)) {
          const file = `releases/${r.version}.md`;
          const body = await convertWithImages(r.html, 'releases', r.version.replace(/\./g, '-'), slugToPath, file);
          await write(file, frontMatter({ title: r.version, date: r.date }) + body);
          report.releases++;
        }
        continue;
      }

      const file = `docs/${group.section}/${page.slug}.md`;
      const body = await convertWithImages(contentHtml, group.section, page.slug, slugToPath, file);
      await write(file, frontMatter({
        title,
        sidebar_label: page.label !== title ? page.label : undefined,
        sidebar_position: pi + 1,
        description,
      }) + body);
      report.pages++;
      console.log(`✓ ${file}`);
    }
  }

  const list = (xs) => (xs.length ? xs.map((x) => `- ${x}`).join('\n') : '- none');
  await write('.design/migration-report.md', `# Migration report

Generated by scripts/migrate/run.mjs on ${new Date().toISOString().slice(0, 10)}.

- Doc pages: ${report.pages}
- Release posts: ${report.releases}
- Images downloaded: ${report.images}

## Notion links (owner to review)

${list(report.notion)}

## Mantle-hosted files (downloaded to .mantle-assets/, not committed)

${list(report.videos)}

## Dead links on Mantle (unlinked, text kept; owner to re-point or delete)

${list(report.deadLinks)}

## Bold-only lines in releases (tidy by hand)

${list(report.boldOnly)}

## Release dates to confirm

- releases/v1.15.0.md and releases/v1.16.0.md are dated 2024 on Mantle (likely 2025).
`);
  console.log(JSON.stringify({ pages: report.pages, releases: report.releases, images: report.images }));
}

main().catch((e) => { console.error(e); process.exit(1); });
